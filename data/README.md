# Catalogo geografico de Colombia

`colombia-divipola.json` contiene los 1.122 municipios, distritos y areas no municipalizadas de los 33 departamentos/distritos de Colombia.

- Fuente: DANE, codificacion DIVIPOLA publicada en Datos Abiertos Colombia.
- Recurso: https://www.datos.gov.co/resource/gdxc-w37w
- Corte local: 2026-09-12.
- Campos conservados: codigo y nombre oficial de departamento, codigo y nombre oficial de municipio.

La aplicacion usa exclusivamente este archivo en tiempo de ejecucion. Los codigos se almacenan y comparan como strings para conservar sus ceros iniciales.
